# 原理图连接信息导出 · 使用说明

把原理图的网络连接导出成 Markdown 文档，供大模型（LLM）开发固件时查阅电路，也方便工程师不打开原理图快速核对连接。

## 解决什么问题

当前用大模型开发固件，让它"看"原理图有两个痛点：

1. **容易出错**：原理图图元密集、常跨多页，模型读图经常看错引脚号、漏看网络连接——生成的代码引脚用错、连接关系搞反，这类低级错误反复调试最浪费时间；
2. **又慢又费 token**：一张复杂板子的截图要消耗大量视觉 token，多轮对话反复贴图，开销惊人，而且不支持多模态的模型根本用不了。

本插件把电路连接**一键导出为结构化文本**，开发时**直接引用到大模型对话 / 工程上下文中**，帮助它准确、快速地理解电路连接——特别是 **MCU、FPGA 程序开发**时，"哪个引脚接到了哪个芯片的哪个脚"一查即得，从源头避免低级错误。

## 安装

嘉立创EDA专业版 → 设置 → 扩展 → 扩展管理 → 扩展上传，选择 `lceda-sch-conn-export_vX.Y.Z.eext`。

> v0.2.0 及更早版本因引用文件保存接口会在安装时提示"外部交互权限默认禁用"；v0.3.0 起已移除全部
> 文件系统/联网接口引用，不再出现该提示（旧版升级后重新导入即可）。

## 快速上手

1. 打开工程原理图（支持多图页，自动全工程收集）；
2. **选中 MCU / FPGA / DSP 等要写程序的器件**（也可以不选，改用设置里的位号）；
3. 菜单「连接信息导出」→「导出连接信息（预览 / 复制 / 下载）」，自动打开结果窗口；
4. 窗口里三选一：**复制全文**（直接粘贴给大模型 / AI 对话框）、**下载 .md**（存进固件仓库，推荐 `docs/board.md`）、全选文本手动复制。

> 全程不联网、不直接读写本地文件，安装时**不会**出现"外部交互权限"提示。
> 全文同时输出到控制台留档（开发者工具，过滤 `sch-connexport`）。

## 逐模块开发：选中器件互联（模块视图）

不需要一次性导出全板——按功能模块开发时，只导出这一部分，审读更快：

1. 在原理图中**框选本功能模块的全部器件**（≥2 个），例如 单片机 + RS485 芯片 + USB 接口座；
2. 菜单「连接信息导出」→「导出选中器件互联（模块视图）」；
3. 得到的文档只有四块：选定器件清单、**器件间互联网络**（逐网络 `网络: 选中侧连接点 = 连接点`，未选中器件以"，外部："标注）、**对外信号引脚**（模块边界：这些脚的网络只连到本模块一处，"=" 后是模块外的连接点）、电源/未连接汇总。

例如选中 MCU(U4) + 485(U7) 后的互联行：

```text
USART1_TX: U4.PA9(19) = U7.DI(2)
RE_DE:     U4.PA8(18) = U7.RE(2) = U7.DE(3)，外部：R6.1
```

模块视图只认画布选中（不并入设置里的核心位号）；电源过滤、紧凑/表格风格等设置与全图导出共用。

## 核心器件怎么定

| 来源 | 说明 |
| --- | --- |
| 画布选中 | 执行命令时选中的器件，只选引脚也会自动定位父器件 |
| 设置位号 | 设置面板「核心器件位号」，如 `U1, U3`，忽略大小写 |
| 自动识别 | 两者皆空时（需在设置中开启），引脚数 ≥ 24 的器件全部视为核心 |

三者关系：选中 ∪ 配置位号；都为空且未开自动识别时命令会提示。

## 电源/地怎么忽略

- 默认忽略名单（设置页可增删，支持 `*` 通配、忽略大小写）：
  `GND, AGND, DGND, GND*, *GND, VSS*, VDD*, VCC*, VREF*, VEE*, VBAT*, VBUS, VIN, VSYS, +3V3, +5V, +1V8, +*, 3V3, 5V, NC` 等；
- 网络名没命中名单时，引脚名形如 VDD/VSS/VCC/GND/EP 的引脚仍按电源脚归类（可在设置关闭）；
- 全部成员都是电源脚的网络（自定义电源轨）整体归入电源；
- 关闭「忽略电源/地网络」总开关可完整保留电源连接（此时电源脚仍单列，不混入信号表）。

## 输出文档结构（默认紧凑风格，省 token）

1. **核心器件**：每个核心器件一段代码块，每行 `引脚号 引脚名 网络 = 对端列表`，对端连接点为 `位号.引脚名(引脚号)`（如 `U5.SCL(6)` = U5 的 6 脚 SCL，能直接回答"MCU 42/PB8 连到哪个芯片的哪个脚"）；未连接引脚与电源脚各压成单行；
2. **信号网络清单**：默认只列**不经过核心器件**的网络（核心相关网络已在核心表完整展开，不重复罗列；可切回全量）；
3. **其它器件一览**：`位号 型号: 引脚名(引脚号)=网络 …` 一行一器件；
4. **已忽略的电源/地网络**：`网络名(连接数): 连接点` 一行一网络（超 24 处自动截断）。

设置面板可切换：紧凑文本 / Markdown 表格风格、网络清单范围（只列非核心 / 全量）、是否标注引脚电气方向 [I]/[O]/[IO]；章节 2/3/4 与未连接行均可独立开关；导出文件名前缀可配置（默认 `schematic-connections-日期.md`）。

## 常见问题

- **提示"没有可用的核心器件"**：先在图中选中器件，或在设置面板填位号，或开启自动识别；
- **引脚都显示未连接**：网表读取失败（原理图未打开或客户端不支持），弹窗与控制台会有提示；
- **提示若干连接点未匹配**：多为多子部件器件或特殊位号形态，不影响其余内容；明细在控制台（过滤 `sch-connexport`）；
- **预览窗口内容被截断**：导出内容超过 40 万字符时窗口缓存截断（下载自动禁用），完整全文在控制台（过滤 `sch-connexport`）可复制；
- **下载按钮没反应**：个别客户端 webview 禁用了浏览器下载，请改用「复制全文」。
